Which page matches the original? A blind test

An AI built web pages from an original design in different ways. For each item you see the original page, then two AI-built pages, A and B, with no labels. Pick the one that looks more like the original's design: its colours, fonts, spacing and layout. Judge the look, not which page you like more or which has more content. It takes about 15 minutes, and you need a GitHub account to submit.

  1. Open the list of submissions and pick a packet (P1 to P6) that nobody has taken yet. Each packet needs one person. Please don't read other people's picks.
  2. Open your packet below. It has five tasks with two pairs each, so ten picks.
  3. Submit one rating form: choose your packet, put it in the title (for example "[C3 rating] P2"), and give each pick with one line on why. Submit once.

The pages were built by an AI for this test. If you helped make them, please don't rate.
